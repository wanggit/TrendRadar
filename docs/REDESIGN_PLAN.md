# TrendRadar 页面深度改造计划

> **目标**：将项目的两套前端页面（HTML 报告页面 + 可视化配置编辑器）全面改造为 **新拟态/玻璃拟态风格 + 侧边栏导航**，与原有设计完全区分。
>
> **创建日期**：2026-05-06
> **状态**：🔄 开发完成（阶段一二三全部闭环，阶段四待手动浏览器验证）

---

## 整体设计方向

| 维度 | 方案 |
|------|------|
| **视觉风格** | 玻璃拟态 (Glassmorphism) + 新拟态 (Neumorphism) |
| **布局模式** | 左侧固定导航栏 + 右侧内容区 |
| **配色方案** | 柔和渐变背景（蓝紫/粉紫），白色半透明卡片 |
| **核心特征** | 半透明背景 + backdrop-filter 模糊 + 柔和内外阴影 |
